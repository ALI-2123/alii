Install in four steps

It takes about two minutes.

  1. Download the installerPress the download button and save Blade-Client-Setup.exe.
  2. Run itFollow the installer. A Blade Client shortcut appears on your desktop.
  3. Pick a versionOpen Blade Client, choose 1.21.1, 1.21.4 or 1.21.11, and set the loader to Fabric.
  4. Install the mod and playOpen the Mods page, press Install performance pack, then Install Blade mod. Press Play.

Questions

Does it work on Mac or Linux?

Not yet. The installer is for Windows only.

Why does Windows show a warning?

The installer is not signed with a paid certificate, so Windows does not know the publisher yet. Choose More info, then Run anyway.

Which Minecraft versions can I play?

The Blade mod supports 1.21.1, 1.21.4 and 1.21.11. Other versions still launch, but without the Blade mod.

Do my friends need Blade too?

Yes. Friends, chat and cosmetics only show up between people who run Blade.
